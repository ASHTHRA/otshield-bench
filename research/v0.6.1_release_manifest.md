## Study Design

The retained study contains 25 trials across five conditions:

- `clean`
- `delay20`
- `delay20_jitter5_loss5`
- `delay40_jitter10`
- `delay60_jitter10`

Each condition run planned 60 read-only Modbus/TCP Function Code 3
transactions. The complete study planned 7,500 transactions and produced 250
paired detector evaluations.

The robust detector threshold was frozen independently from historical clean
calibration and was not tuned using the v0.6.1 study results.

## Evidence Distribution

The Git repository retains the versioned study records used by the project.
The complete local study directory, including run-level evidence covered by
`STUDY_SHA256SUMS`, is intended to be packaged separately as a release asset.

The release asset must not be created from modified evidence and must not contain
credentials, API keys, private SSH material, or unrelated runtime files.

## Scientific Boundaries

The evidence covers only the documented isolated OpenPLC laboratory and
read-only Modbus/TCP Function Code 3 timing workload.

No claim is made of:

- production validation;
- completed independent external replication;
- DNP3 experimental validation;
- EtherNet/IP experimental validation;
- universal detector superiority;
- industry adoption.

Resource instrumentation measures detector prediction CPU/wall time and Python
`tracemalloc` peak allocation only and does not measure complete deployment or
system cost.
