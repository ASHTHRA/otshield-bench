# v0.6 implementation and operation

The preregistered `v0.6_experiment_protocol.md` is unchanged. No v0.6 laboratory
results were collected while implementing this workflow. Tests use synthetic
fixtures; they are not experimental evidence.

`v0.6_calibration.json` freezes 195 eligible intervals from the five historical
clean runs in `evidence/repeatability/20260920T182506Z`. Its threshold is
100.23721899414062 ms. Calibration requires at least 30 finite positive intervals
and positive finite MAD. It uses only matched, explicitly non-anomalous clean
observations. The JSON records historical observation and protocol hashes, study
hash and execution/aggregation commits. Regenerate with
`python scripts/calibrate_v06_detector.py`; arbitrary source roots are rejected.

The paired evaluator accepts only the SHA-256-pinned frozen calibration JSON.
Neither the per-run protocol nor captured traffic can override its threshold.
The baseline threshold is fixed at 50 ms. Both evaluations consume the same
normalized document; detector inputs have labels cleared. Ground truth remains
in the evaluation layer. Each detector writes its own `.result.json`,
`.result.md`, and `.observations.json`, with common capture and protocol hashes.
The existing v0.5 evaluator interface and protocol-selected behavior remain
available. The new study and aggregate schemas are `OTB-V06-STUDY/0.1` and
`OTB-V06-AGGREGATE/0.1`; existing OTB-RESULT and observation schemas are retained.

From the repository root, activate the installed environment and preflight:

```bash
source .venv/bin/activate
python scripts/run_v06_study.py --dry-run
```

Preflight is the default, also available as `--preflight`. It validates the
frozen calibration and displays the complete rotating schedule. It neither
contacts Docker nor creates output. It reports executable availability, but
does not establish Docker daemon, image-download, or OpenPLC readiness.

Only later, in the explicitly authorized isolated laboratory, after committing
and verifying the implementation, launch with:

```bash
source .venv/bin/activate
python scripts/run_v06_study.py --execute-lab
```

Execution refuses a dirty Git tree and an existing output directory. By default
it creates `evidence/v06/<UTC timestamp>/`; `--output` can choose a new directory,
except under historical repeatability evidence. There is no trial-count override.
The internal shell worker is not a standalone public entry point. It retains the
v0.5 client-egress impairment, server-namespace capture, 60-request read-only FC3
schedule, and per-trial OpenPLC restart. It makes one capture and one normalization
per condition, then invokes the two paired detectors. It does not commit, push,
tag, or publish evidence. Docker images and installed laboratory packages are
recorded through the existing provenance workflow; future runs still depend on
availability of those external images/packages.

A successful study requires 125 validated condition runs, 7,500 planned
transactions, and 250 detector evaluations. The latter count means evaluations
in completed, validated pairs; partially produced results remain in failed-run
directories and are not represented as completed pairs. Every attempted condition
retains its directory. Completion requires all artifacts and their hashes,
preregistered transaction schedule, matching normalization/provenance, and paired
results. A worker failure stops collection without automatic retry. The manifest
retains failed attempts, reasons, unattempted runs, infrastructure failures, and
execution commit; `execution.log` retains worker output. An interruption triggers
worker cleanup and final accounting where the operating system permits it.
Uncatchable termination or power loss can prevent finalization; retained partial
directories must never be silently discarded when documenting any later retry.

Aggregation includes every completed pair, including unfavorable results. It
reports per-condition, per-detector N, mean, sample SD, min, max, and two-sided
95% Student-t intervals for effectiveness and resource metrics. Recall and F1
paired differences are computed within each run as robust minus baseline before
aggregation. SciPy supplies the t quantile. Intervals remain unbounded in JSON;
N=1 has null SD and interval, and conditions with no completed pairs are omitted
from aggregates but remain fully accounted for in the manifest. Study hashes
cover the copied calibration/protocol, execution metadata/log, all run artifacts,
aggregate, and manifest. No universal detector superiority is inferred.

The preserved failed execution and the v0.6-only transport canonicalization
correction are documented in `v0.6_duplicate_tid_erratum.md`. Paired result
and observation metadata now includes an auditable canonicalization decision;
raw normalization remains unchanged. A replacement study must use a new root
and disclose the preserved failed attempt.
